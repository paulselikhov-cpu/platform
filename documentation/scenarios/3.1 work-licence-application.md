# Сценарий №3.1 Заявка на получение рабочей лицензии
1. В приёмной мэрии персонажем вызывается кнопка - заявка на получение лицензии для работы
2. Вызывается POST метод register-work-licence
3. На бэкенде создаётся заявка со статусом pending
5. Пользователю приходит уведомление что заявка создана
4. Авторизованный сотрудник мэрии видит в списке заявок - заявку в статусе pendind
5. Отклоняет или одобряет её
6. При одобрении chatUser присваивается workLicenceId с рендомным значением
7. Пользователю приходит уведомление об обновлении статуса
