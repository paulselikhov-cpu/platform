# Сценарий №3.2 Меню работ
1. После того, как пользователь получил лицензию на работу и паспорт, он может устроиться на работу
2. В приемной мерии персонажем вызывается кнопка "Биржа труда"
3. Появляется меню выбора работ. Меню выбора работ состоит из списка карточек, с описанием работы и требуемым уровнем персонажа.
