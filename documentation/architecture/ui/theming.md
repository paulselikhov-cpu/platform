# Темизация UI: 4 темы и «скин» через design tokens

> Факты о том, как устроено оформление. Здесь же закреплены правила,
> которых нужно придерживаться при добавлении нового компонента.

## 4 темы

Пользователь выбирает одну из 4 тем (см. `settings-menu` / `user-menu`):

| id (`data-theme`) | Название                   | Визуальный стиль                          |
|-------------------|----------------------------|-------------------------------------------|
| `retro-dark`      | Тёмная (олдскул)           | Win XP/2000, тёмно-синие оттенки, bevel    |
| `retro-light`     | Светлая (олдскул)          | Win XP/2000, нейтральные тёмно-бежевые тона|
| `modern-dark`     | Тёмная (современная)       | современный мессенджер, тёмная             |
| `modern-light`    | Светлая (современная)      | современный мессенджер, светлая            |

- Олдскул = квадратные углы (`--radius-*: 0`), моноширинный шрифт
  (`--font-ui` = Courier), bevel-кнопки, жёсткие тени-смещения,
  титульная полоса с синим градиентом.
- Современные = скруглённые углы, системный шрифт без засечек,
  плоские акцентные кнопки, мягкие тени.

Все значения задаются ТОЛЬКО токенами в `design-tokens.scss`. Каждой теме
соответствует свой блок `[data-theme=...]`; блок `retro-dark` дополнительно
сдвоен с `:root` для первичной отрисовки до загрузки JS.

## Где что лежит

- `app/tokens/design-tokens.scss` — CSS-переменные всех 4 тем + общие размеры
  (`:root`). Подключается ОДИН раз глобально через `src/styles.scss`
  (`@use 'app/tokens/design-tokens' as *;`). Компоненты сами его **не**
  подключают — только используют `var(--...)`.
- `app/tokens/mixins.scss` — `@mixin`и (кнопки, инпуты, панели, пилюли и т.п.)
  без CSS-вывода. Компоненту, которому нужен миксин, достаточно
  `@use '.../mixins' as *;` — токены при этом не дублируются.
- `app/services/theme.service.ts` — enum `Theme` из 4 id, применяет
  `data-theme` на `<html>`, хранит выбор в localStorage
  (ключ `babich-chat-theme`) и мигрирует старые ключи (
  `dark→retro-dark`, `light→retro-light`, `retro/cold-retro/amber-retro→retro-dark`).

## «Скин»-токены (различие олдскул/современный)

Одни и те же имена токенов в разных темах дают разный вид. Ключевые:
- `--radius-sm/md/lg/full` — скругления (олдскул `0`, современные 6/10/14/999).
- `--font-ui` (синоним `--font-mono` в текущей кодовой базе) — шрифт интерфейса.
- `--shadow-window/dialog/popover/card` — тени (жёсткие vs мягкие).
- `--backdrop-bg` — затемнение подложек модалок.
- `--border-w` — толщина бордеров (олдскул `2px`, современные `1px`).
  Применяется в миксинах `base-input`/`btn-*` и точечно в компонентах
  вместо хардкода `2px`/`1px`.
- `--btn-radius`, `--btn-primary-*`, `--btn-secondary-*` — внешний вид кнопок
  (bevel-грани для олдскула, плоская заливка для современных).
- `--color-raised-top/sunken` — приподнятые/утопленные поверхности (bevel).
- `--window-border-width/radius`, `--color-title-bar-bg` — окна и титульная полоса.

## Семантика цветовых токенов

- `--color-success` / `--color-danger` — цвет текста и рамки;
- `--color-success-muted` / `--color-danger-muted` — мягкая заливка
  (кнопки, бейджи) поверх панелей;
- `--color-warning` — нейтральный жёлтый (нет `*-muted`, для пилюль
  используется прозрачный фон + цветная рамка);
- `--color-sunken` — тёмная утопленная поверхность («инсет»-панели).

## Правило: новый компонент = сразу в 4 темах

Если делаешь новый shared- или фича-компонент:

1. **Все цвета/отступы/скругления/шрифт/тени берутся из `var(--...)`**,
   никаких `#hex`/`rgba`/`Courier New` в файле компонента.
2. **Если нужного токена нет — добавь его** в `design-tokens.scss` во
   **все четыре** темы (`retro-dark`, `retro-light`, `modern-dark`,
   `modern-light`), с осмысленными значениями для «олдскул» и «современный».
3. Повторяющееся оформление (кнопка, инпут, панель, пилюля) — **выносится в
   миксин** `app/tokens/mixins.scss`, не копируется.
4. **Повторяющийся компонент** (модалка, кнопка, бейдж, таблица) — **выносится в
   `shared/components/`**, дочерние уникальные части — как его панели/сабкомпоненты.
5. Шаблон и стили — в отдельных файлах (`<name>.html` / `<name>.scss`), не inline.
6. Токены-темы НЕ подключаются через `@use 'design-tokens'` в компоненте —
   это дублирует весь CSS тем в каждый компонент и раздувает бюджет.
   Миксины — через `@use '.../mixins' as *;`, а `var(--...)` работают сами.

## Миграция с 5 тем

Старый enum (`dark`, `light`, `retro`, `cold-retro`, `amber-retro`)
упразднён. Сохранённый выбор в localStorage автоматически переносится в
`retro-dark` / `retro-light`; коричневые/янтарные темы (по ТЗ — «без
коричневого» в тёмной олдскуле) заменены на тёмно-синюю `retro-dark`.
