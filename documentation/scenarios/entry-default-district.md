# Сценарий №1. Первый вход в дефолтный район

## Цель
Новый пользователь регистрируется, попадает в игру, выбирает район, видит системные локации и может начать взаимодействие с игровым миром.

---

## Шаг 1. Регистрация

**Пользователь:** заполняет форму регистрации (логин, email, пароль).

**Система:**
- POST `/api/auth/register` — создаёт пользователя и JWT-токен
- Редиректит на `/chat`

> ✅ **Статус:** Реализовано. `RegisterComponent` → `AuthService.register()` → `router.navigate(['/chat'])`.

---

## Шаг 2. Главное меню (приветственная заставка)

**Текущее поведение:** после регистрации/логина пользователь сразу попадает в чат (`/chat`).

**По сценарию:** должен показываться экран приветствия с информацией о платформе и пунктами:
1. **Создать персонажа / Войти** — переход к выбору района
2. **Выйти** — возврат на экран логина

В будущем на этом экране могут отображаться новости платформы, события и т.д.

> ❌ **Статус:** Не реализовано. Требуется создать компонент главного меню (отдельный роут `/main-menu`).

---

## Шаг 3. Выбор района

**Пользователь:** нажимает «Войти» → видит список доступных районов.

**Система:**
- GET `/api/districts` — загружает список районов
- На старте доступен один район: **Центральный** (code: `CENTRAL`)
- Пользователь выбирает район → переход в чат с этим районом

> ❌ **Статус:** Не реализовано. Требуется экран выбора района после главного меню.

**API уже готов:** `GET /api/districts` возвращает `[{id, code, name, description, systemLocations}]`.

**Frontend-модели уже есть:** `District`, `DistrictService`.

---

## Шаг 4. Вход в игру — сайдбар / чат

**Пользователь:** после выбора района попадает в основной интерфейс чата.

**Система:** загружает:
1. **Приватные локации пользователя** — `GET /api/locations/my?userId=N` (если есть)
2. **Районы с системными локациями** — `GET /api/districts`

**Что видит пользователь:**
- В сайдбаре — секция **«Мои локации»** (пустая, если нет ни одной) и секция **«Системные локации»** с районом «Центральный» и его 8 локациями:
  - 🏛️ Мэрия
  - 🏛️ Площадь Ленина
  - 🏛️ Полицейский участок
  - 🏛️ Тюрьма
  - 🏛️ Банк
  - 🏛️ Склад
  - 🏛️ Рынок
  - 🏛️ Рынок недвижимости
- По умолчанию никакая локация не выбрана, основная панель пуста
- Во всех локациях пользователь оффлайн

> ✅ **Статус:** Частично реализовано.
> - Сайдбар загружает районы и отображает их ✅
> - Приватные локации загружаются ✅
> - По умолчанию панель пуста ✅
> - **Клик по системной локации не работает** ❌ — `.public-location-item` не имеет обработчика
> - **LocationView не поддерживает системные локации** ❌ — ожидает поля `template`, `inviteCode`, `isPublic`

---

## Шаг 5. Навигация по системным локациям (целевое поведение)

**Пользователь:** кликает на системную локацию в сайдбаре (например, «Площадь Ленина»).

**Система:**
- Загружает комнаты системной локации — `GET /api/locations/{id}/rooms`
- Отображает список комнат (для Площади Ленина: «Площадь», «Тёплые трубы»)
- Пользователь выбирает комнату → открывает чат

> ❌ **Статус:** Требует доработки frontend.

### Что нужно сделать:
1. **Сделать `.public-location-item` кликабельным** — добавить `(click)` с эмитом события выбора системной локации
2. **Адаптировать `LocationView` для системных локаций** — поля `template`, `inviteCode`, `isPublic` должны быть опциональными, создать отдельный компонент `SystemLocationView`
3. **Проверить API:** `GET /api/locations/{id}/rooms` должен работать для системных локаций (где `isSystem=true`)

---

## Шаг 6. Переход к Сценарию №2

После первого входа в район пользователь оказывается в чате. Далее запускается **[Сценарий №2. Первые выборы](the-first-election.md)** — механика выборов губернатора района на Площади Ленина.

## Технические заметки

- API для районов: `GET /api/districts`, `GET /api/districts/{id}`, `GET /api/districts/{id}/system-locations`
- Frontend модели: `District` (с полем `systemLocations: ILocation[]`), `PublicLocationType` enum
- Системные локации — это `Location` с `isSystem=true`, они хранятся в той же таблице `locations`
- У системных локаций есть комнаты (`Room`), созданные в `DataInitializer`
