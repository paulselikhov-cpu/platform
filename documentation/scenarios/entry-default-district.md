При регистрации, пользователь сначала заполняет параметры персонажа.
После этого он падает в меню выбора района. По дефолту уже будет 1 район.
Пользователь может выбирать любой дефолтный район (cоздавать пока не может).
После захода в дефолтный район, пользователь попадает в сайдбар, где видит список системных локаций.
