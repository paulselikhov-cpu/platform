# Сценарий №1. Первый вход в дефолтный район

## Цель
Новый пользователь регистрируется, попадает в игру, выбирает район, видит системные локации и может начать взаимодействие с игровым миром.

---

## Шаг 1. Регистрация

**Пользователь:** заполняет форму регистрации (логин, email, пароль).

**Система:**
- POST `/api/auth/register` — создаёт пользователя и JWT-токен
- Редиректит на `/main-menu`

> ✅ **Реализовано.** `RegisterComponent` → `AuthService.register()` → `router.navigate(['/main-menu'])`.

---

## Шаг 2. Главное меню (приветственная заставка)

**Пользователь:** после регистрации или логина видит приветственный экран.

**Система:** показывает карточку с:
- Названием платформы «BabichChat»
- Кратким описанием
- Кнопкой **«🎮 Войти»** — переход к выбору района (`/district-select`)
- Кнопкой **«🚪 Выйти»** — логаут и возврат на экран логина

В будущем на этом экране могут отображаться новости платформы, события и т.д.

> ✅ **Реализовано.** Компонент `MainMenu` (роут `/main-menu`).
> - После регистрации → `/main-menu`
> - После логина → `/main-menu`
> - «Войти» → `/district-select`
> - «Выйти» → `AuthService.logout()`

---

## Шаг 3. Выбор района

**Пользователь:** нажимает «Войти» в главном меню → видит список доступных районов.

**Система:**
- GET `/api/districts` — загружает список районов
- На старте доступен один район: **Центральный** (code: `CENTRAL`)
- Каждый район показывается карточкой: название, описание, теги системных локаций
- Пользователь выбирает район → сохраняется в `localStorage` → переход в чат (`/chat`)

> ✅ **Реализовано.** Компонент `DistrictSelect` (роут `/district-select`).
> - API: `GET /api/districts`
> - После выбора: `localStorage.setItem('selectedDistrict', ...)` + `router.navigate(['/chat'])`

---

## Шаг 4. Вход в игру — сайдбар / чат

**Пользователь:** после выбора района попадает в основной интерфейс чата.

**Система:** загружает:
1. **Приватные локации пользователя** — `GET /api/locations/my?userId=N` (если есть)
2. **Районы с системными локациями** — `GET /api/districts`

**Что видит пользователь:**
- В сайдбаре — секция **«Мои локации»** (пустая, если нет ни одной) и секция **«Системные локации»** с районом «Центральный» и его 8 локациями с соответствующими иконками:
  - 🏛️ Мэрия
  - 📢 Площадь Ленина
  - 👮 Полицейский участок
  - 🔒 Тюрьма
  - 🏦 Банк
  - 📦 Склад
  - 🛒 Рынок
  - 🏘️ Рынок недвижимости
- По умолчанию никакая локация не выбрана, основная панель пуста (`LocationEmpty`)
- Во всех локациях пользователь оффлайн

> ✅ **Реализовано.** Sidebar загружает районы (`DistrictService.getAllDistricts()`),
> отображает системные локации с иконками, приватные локации загружаются.

---

## Шаг 5. Навигация по системным локациям

**Пользователь:** кликает на системную локацию в сайдбаре (например, «Площадь Ленина»).

**Система:**
- Локация подсвечивается (активный стиль с левой рамкой)
- Открывается `LocationView` с заголовком локации и бейджем **«Системная»**
- Загружаются комнаты системной локации — `GET /api/locations/{id}/rooms`
- Отображается список комнат (для Площади Ленина: «Площадь», «Тёплые трубы»)
- Пользователь выбирает комнату → открывается чат (`ChatArea`)

> ✅ **Реализовано.**
> - `.public-location-item` кликабелен с эмитом `systemLocationSelected`
> - `LocationView` адаптирован: поля `template`, `inviteCode`, `isPublic` — опциональны
> - API `GET /api/locations/{id}/rooms` работает для системных локаций
> - Бейдж «Системная» отображается акцентным цветом

---

## Технические заметки

### Схема навигации (роутинг)
```
/login → /main-menu → /district-select → /chat
/register ↗
```

### API
- `GET /api/auth/register` — регистрация
- `GET /api/auth/login` — логин
- `GET /api/districts` — список районов с системными локациями
- `GET /api/districts/{id}` — район по ID
- `GET /api/districts/{id}/system-locations` — системные локации района
- `GET /api/locations/{id}/rooms` — комнаты локации (работает и для системных)

### Frontend
- `ILocation` — универсальный интерфейс (поля `template`, `inviteCode`, `isPublic` — опциональны, добавлено `type?: string`, `memberRole?: 'SYSTEM'`)
- `Sidebar` — эмитит `systemLocationSelected` для системных локаций, словарь иконок по `PublicLocationType`
- `MainMenu` — приветственная заставка (роут `/main-menu`)
- `DistrictSelect` — выбор района (роут `/district-select`)
- `LocationView` — работает и с системными, и с пользовательскими локациями

### Backend (уже было реализовано)
- `DataInitializer` — создаёт район «Центральный» + 8 системных локаций с комнатами при старте
- `DistrictController` — REST API для районов
- `LocationController.getRooms()` — работает для любой локации по ID
